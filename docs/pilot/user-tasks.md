# 好約操作體驗（約 10–15 分鐘）

這是虛構牙醫診所的原型，不會建立真實掛號。請不要輸入個資。沒有標準說法；我們想知道介面是否讓你理解，不是在測你的操作能力。卡住可以說出來，也可以隨時停止。

請開啟提供的示範連結並選一位虛構患者。

1. 先不要操作，請用自己的話說：你覺得這個工具可以幫你做什麼？接下來你會做什麼？
2. 你想調整目前預約時間，同時保留預約。請用你自己的話告訴它，選一個適合的時間；先停在你認為還沒有真正更動的位置。
3. 告訴主持人：現在儲存的是哪個時間？你怎麼知道？如果確定要改，請繼續完成。
4. 重新整理頁面，找出目前預約的日期、時間與醫師。
5. 你想找櫃台人員協助，請試著提出需求。你認為現在有真人回覆了嗎？你依據哪個畫面判斷？
6. 哪一步最不確定？如果這是你平常看診的診所，你會想用它、選單／表單，還是直接聯絡櫃台？為什麼？

不需要給好評；看不懂、做錯或不想用，都是有用的結果。
