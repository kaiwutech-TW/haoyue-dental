# 3-minute demo plan / 三分鐘展示腳本

Use the English live page for international judges. Switch once to Traditional Chinese. Never show credentials, private staff cases, browser history or customer spreadsheets. A video is not recorded until a real recording file exists.

| Time | Action | English narration |
|---|---|---|
| 00:00–00:15 | Cover, then the English phone + trace page | “A chatbot can sound helpful and still change the wrong appointment. HAOYUE connects understanding with a transaction you can inspect and confirm.” |
| 00:15–00:40 | Select Claire Lin; type “Not cancel—please reschedule my appointment” | “This is free text. Our fine-tuned NVIDIA 4B model scores eight intents in one forward pass. The panel shows the actual adapter and result.” |
| 00:40–01:10 | Select a slot; show original booking; confirm; read updated version | “The model cannot write an appointment. Application rules check ownership, availability and version. Only this confirmation commits the change. A repeated confirmation does not write again.” |
| 01:10–01:30 | Type “I clicked by mistake. I don’t know how to use this” | “Confusion gets patient instructions. We do not guess someone’s age. Repeated requests skip another model call while preserving the pending choice.” |
| 01:30–01:45 | Type “Talk to staff”; show actual handoff event | “Medical questions and requests for a person become real handoff cases. We never pretend someone has replied.” |
| 01:45–02:05 | Scroll to technology section, show architecture | “Nebius provides NVIDIA 30B fallback. Supabase performs atomic storage. Tavily supports staff research with human approval, rather than searching on every patient message.” |
| 02:05–02:35 | Show metrics and limitations | “The fixed synthetic test improved from 52 to 58 correct out of 64. One accepted high-score answer was still wrong. The local median was 53 milliseconds, excluding network. These are engineering results, not clinical validation.” |
| 02:35–02:55 | Switch to Chinese; show the original colloquial correction and public source/tutorial | “The primary training language is Taiwanese Mandarin. English is also interactive, with its own documented smoke tests. The full recipe, failed first calibration and costs are public.” |
| 02:55–03:00 | End card with live demo URL | “Understand. Confirm. Complete.” |

The live site has source and session limits. Plan the recording before starting and avoid wasting trial sessions. Use the app's normal controls. Do not reset shared spending counters to obtain a cleaner take.
